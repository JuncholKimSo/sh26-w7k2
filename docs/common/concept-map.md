# 개념 지도 — 한국사회사의 주된 개념들

> 2주차 강의의 재료. 소장 논문 바깥까지 넓혀 한국사회사·역사사회학이 축적한 개념 24개와 대표 문헌을 정리했다(2026-07-22 웹 조사, 서지는 RISS·KCI·DBpia·출판사 페이지에서 확인된 것만 [확정] 표기). 2주 강의노트는 이 노트에서 발췌해 쓴다.
> ★ = 소장 논문 있음(카탈로그 링크). ⚠️ = 서지 일부 미확인.
