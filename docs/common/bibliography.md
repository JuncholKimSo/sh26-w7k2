# 참고도서 — 사회사·역사사회학 방법론 단행본

> 한국사회사학회(1980 창립, 초기 명칭 한국사회사연구회)의 방법론 서적 계보를 한 세트로 소장하게 됨(2026-07-22, 사용자 제공 스캔 PDF 6권). 위치: `~/Desktop/08_LECTURE/2026_2_JNU_한국사회사/참고도서/`. 모두 텍스트 레이어 없는 스캔본(100MB 초과 다수 — 열람은 뷰어로, 텍스트 추출은 pdftoppm+OCR 필요).
> 쓰임: **1주 OT**(사회사=사회학의 방법 / 한국으로의 도착 1980~86)와 **2주 개념 지도**(학술장·근대성 논쟁)의 재료. 특히 **김백영 외 2016은 한국 최초의 사회사/역사사회학 교재** — 1장 「고전사회학과 역사사회학」이 1주 OT의 국문 텍스트로 버크 1장과 나란히 쓸 수 있고, 4장 「한국 사회사 연구의 형성과 발전」이 2주 학술장 절의 국문 개설. 최신 학설사·방법론이 반영된 유일한 국문 교재이므로 2주 배포물 '더 읽을 것' 맨 앞에 둔다.

## 계보 한눈에
1982 신용하 편 『사회사와 사회학』(서구 논의 국역 총집) → 1986 『한국 전통사회의 구조와 변동』(논문집 1집 — 첫 실증) → 1988 『사회사 연구의 이론과 방법』(논문집 — 서구 논자 소개) → 1993 『한국 사회사 연구의 전통』(논문집 39? — 한국 선학 재조명) → 1995 『한국사회사의 이해』(총서 1, 개론) → **2016 김백영 외 『사회사/역사사회학』(사회학총서 — 교재)**. 34년에 걸친 "국역 → 실증 → 서구 소개 → 자기 계보 → 개론 → 교재"의 순서 자체가 1주 OT의 '한국으로의 도착' 서사.

## 1. 김백영 외 (2016), 『사회사/역사사회학』, 다산출판사 (한국사회학회 사회학총서)
- **성격**: 한국사회학회 사회학총서(정진성 회장 재임기 기획, 송호근 발간위원장) 중 한 권. "한국 최초의 사회사/역사사회학 교재"(기획의 글). 공저자 대표 김백영. 514쪽(스캔 기준).
- **기획의 글 「한국 사회사/역사사회학의 토착화를 위하여」** — 1주 OT 서사와 정확히 겹침: 마르크스·토크빌·베버·뒤르켐에게 역사는 필수 구성 요소, 스카치폴("사회학은 본질적으로 역사에 기초를 두고 역사를 지향하는 학문"), 밀즈의 경고(1950년대 미국 사회학의 '현재에 후회하는' 사회학) → 한국 사회사의 효시 이상백·김두헌·김영모·박영신·신용하·최재석 → 1970년대 후반 '사회학과 역사학의 대화', 1980년 한국사회사연구회 창립, 『한국사회사연구회논문집』(1986~96)·『사회와 역사』(1997~) → 1980년대 마르크스주의 → 1990년대 포스트모더니즘·식민지 근대성 논쟁 → 21세기 과제(민족사→인류사·지구사, 탈식민·탈냉전 패러다임, 동아시아 지역).
- **차례** (4부 14장):
  - 1부 사회사/역사사회학의 형성과 발전 — 1장 고전사회학과 역사사회학(박상현: 마르크스와 '역사과학' / 베버와 '성좌'로서의 역사 / 뒤르켐과 진화로서 역사) / 2장 유럽 사회사 연구의 흐름(김백영·정준영: 아날학파 — 페브르·브로델·르 고프, 르 루아 라뒤리, 로버트 단턴) / 3장 미국 역사사회학의 성립과 변천(김경일) / 4장 한국 사회사 연구의 형성과 발전(김민환·박명규: 궤적 I '근대를 발견하다' / 궤적 II '근대를 문제화하다' — 식민지 근대성 논의, 민족주의 패러다임 극복, 페미니즘)
  - 2부 연구의 이론과 방법 — 5장 구조 분석과 거시사 연구(강진연: 폴라니·월러스틴·틸리·브레너·스카치폴) / 6장 인과성, 구조, 사건(채오병·전희진: 사건사·다사건 분석·경로의존) / 7장 사회사/역사사회학의 자료와 그 이용(서호철: 역사자료 웹 DB·아카이브, 계량적 자료와 역사통계, 일기·편지·구술·이미지)
  - 3부 한반도와 동아시아 사회 변동의 거시적 설명 — 8장 한국의 민족주의·민족과 국가(정일준) / 9장 전쟁의 사회사(정근식) / 10장 '역사의 새'가 본 동아시아 근대 500년(김상준)
  - 4부 한국 사회문화 변동의 미시적 이해 — 11장 도시의 사회사(김백영) / 12장 여성사·가족사 / 13장 의식주의 일상생활사 / 14장 소수자·인권 (13·14장 저자는 목차 뒷면 미확인)
- **강의 활용**: **1주 OT 1회차** — 1장 박상현을 버크 1장의 국문 대응으로(고전 3인의 역사적 방법). **2주 개념 지도** — 4장(한국 사회사 연구사 개설, 정근식 2013·강성현 외 2013의 교재판), 6장(사건사·경로의존 — 방법 개념군), 7장 서호철(자료 — 4주 워크숍의 교재판, 「디지털 자료 찾기」와 짝). **6주** 10장 김상준(중층근대의 동아시아판). **10주** 9장 정근식(전쟁의 사회사). **11주** 11장 김백영(도시의 사회사). 학생 추천: 『한국사회사의 이해』(1995) 대신 또는 함께 — 이쪽이 최신.
- 소장 저자 논문과의 대응: 김백영 2006, 김상준 2007, 정근식 2002·2013, 채오병 2019, 서호철 2013, 박명규 2001·1988, 김민환(강성현 외 2013 참여).

- **강의 활용**: **3주(개념의 양적 재점검)의 핵심 교재** — 통계는 사회를 비추는 거울이 아니라 통치 장치이며 식민성과 근대성이 착종된 산물. 4주(『통계연보』·호구조사 자료를 읽을 때의 주의), 6주(식민지 근대성 — 김백영·서호철과 같은 계보), 10주(인구를 세는 국가 — '보호'의 전제). 발췌는 박명규·서호철 2003 노트와 각 주차 강의노트에.
