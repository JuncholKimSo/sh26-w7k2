# 시드 자료 이용 규칙 (12·3 내란 이후 광장의 시민발언·비상행동 자료)

1. 수업에서 배포하는 것은 **교수가 정제한 판본**뿐이다(익명화·ID 부여·민감 정보 제거). 원본은 배포하지 않는다.
2. **발언은 발언 ID로 인용**한다(예: `[S-0231]`). 이름·소속·장소가 특정되는 표현을 원고에 옮기지 않는다.
3. **재식별을 시도하지 않는다**: 유튜브·기사·SNS와 대조해 발언자를 찾는 행위 금지.
4. 자료는 **이 수업의 과제 목적으로만** 쓴다. 외부 공유·재배포·SNS 인용 금지.
5. 발언자는 광장에서 자기 이름으로 말했더라도, 여기서는 **연구 자료의 제공자**로 대한다: 조롱·평가의 대상이 아니라 읽어야 할 텍스트.
6. 자료의 한계를 원고에 적는다: 발화층(채록된 것)만 있고 신청층·침묵층은 없다는 것("자료의 부재도 자료이다").
