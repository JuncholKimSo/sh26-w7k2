# 통계는 어디서 오는가 — 3주 전에 읽어 둘 것

- **통계란**: 통계법 3조 — 정책 수립·평가, 사회 현상 연구를 위해 작성하는 수량 정보. 항목과 분류체계는 역사적 산물이다. 말 자체가 국가(state)에서 왔다(박명규·서호철 2003 — 3주 발췌).
- **조사통계 vs 보고통계**: 직접 세는 것(인구총조사=센서스) vs 행정 보고를 모은 것(주민등록·업무통계). 같은 '인구'라도 출처가 다르면 수가 다르다.
- **1차 vs 2차**: 직접 생산(총조사) vs 재가공(추계·지수).
- **표준분류**: 산업(KSIC 1963~)·직업(KSCO 1963~)·질병(KCD 1952~) — 분류가 바뀌면 시계열이 끊긴다. 기준연도 개편(GDP)·행정구역 개편(1988 광주 광산군 편입)도 마찬가지.
- **장기 추계**: 매디슨 프로젝트, 낙성대경제연구소 장기통계 — 원자료가 없는 구간은 추계. 식민지기 GDP 추계 자체가 논쟁의 당사자.
- **없는 것**: 0과 결측은 다르다. 안 센 것인가, 세고도 안 보여준 것인가(총독부 '비밀' 통계).

## KOSIS 다루기 (2회차 실습)
1. kosis.kr 로그인 → 검색창에 지표명(예 "합계출산율") 또는 국내통계 > 주제별로 찾기.
2. 통계표 열기 → 상단 '시점' 조정(가능한 가장 이른 해부터) → '항목·분류' 조정.
3. 다운로드(CSV/XLSX) → 열: 연도·값·단위 + **출처 URL·통계표명·접속일**을 첫 줄 주석 또는 별도 열에 적는다.
4. 꺾은선 1장(축 시작점·단위 명기) → 변곡점 하나 → 세 문장("보여주는 것 / 못 담는 것 / 다른 지표를 고르면").
개념별 지표 후보는 [`week03/data/indicator_hints`](../../week03/data/indicator_hints.html).

## 세 가지만 묻자
1. 이 지표는 조사통계인가 보고통계인가 — **누가 만들었나?**
2. 0이거나 비어 있는 연도는 그 일이 없었던 건가, **안 센 건가?**
3. 같은 개념에 다른 지표를 고르면 **반대 이야기**가 나오는가?
