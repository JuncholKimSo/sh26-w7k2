# 기말시험 (15주, 20점)

* **무엇을**: 교수가 제공하는 데이터를 기반으로, 사회사의 방법론과 시각으로 재해석하기.
* **언제**: 15주 (12/15 화 · 12/17 목).
* 데이터·형식·분량 등 세부는 추후 이 페이지와 수업에서 안내한다.

## 평가에서 고려하는 것 (형식적·내용적 완성도는 기본)
* 다양한 자료를 검토·사용하는지.
* 같은 현상의 다른 주장을 찾아 교차 검증했는지.
* 검색 실패나 자료의 부재를 어떻게 재해석하는지.
* 개인의 경험·관찰과 어떻게 연결하여 생각하는지.
* 한국사회/근대사회와 해당 사유의 관계와 맥락을 파악하려 시도하는지.
