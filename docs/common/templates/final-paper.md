# 기말 원고 「우리 일상의 미래」 (A4 4~5매, 30점, 기말고사 대체)

**재료** — ① 시드 자료(12·3 광장 시민발언·비상행동 자료, 교수 정제본)에서 고른 일상 주제 ② 스스로 확보한 과거 자료(4주 워크숍 절차로, 2계열 이상 권장) ③ 강독 논문 2편 이상.

**구조(권장)**
1. 주제와 질문 — 시드 발언(ID로 인용)에서 출발: 그 발언이 말하는 일상의 사물·제도·감각은 무엇인가.
2. 지층 — 그 주제의 과거를 보여주는 자료. 시간축(조선 후기 / 식민지 / 개발연대 / 현재) 어느 층까지 내려갔나. **"내 주제는 개념 지도의 어느 개념에 기대는가"** 한 절.
3. 강독 논문과 엮기 — 8주 미니 논증에서 빌린 논증을 이 주제에 적용해 보면(가능성과 한계).
4. **"자료의 부재"** 한 절 — 찾았으나 없었던 것, 침묵층(신청층·발화층·침묵층).
5. 시각화가 있다면 "보여주는 것 / 숨기는 것" 두 문장.
6. 미래 — 이 일상은 어디로 가는가. 예측이 아니라 자료가 허락하는 만큼.

**평가에서 보는 것** — 완성도보다: 다양한 자료(DB)를 썼는가 / 자료끼리 교차 검증했는가 / 검색 실패와 부재를 기록했는가 / 인용 규범(출처·접속일·발언 ID)을 지켰는가 / 강독 논문의 논증을 실제로 썼는가.
**제출** — 15주 2회차 폼 + 출력본 1부. 3인 1조 상호 독해("자료가 말하게 한 것 하나 / 자료가 없어서 못 말한 것 하나").
