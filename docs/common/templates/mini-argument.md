# 미니 논증 — 빌린 논증을 다른 대상에 적용하기 (A4 2매 내외, 10점)

5~7주 강독 논문 6편(박명규 2001 / 조계원 2016 / 김상준 2007 / 김백영 2006 / 이용기 2009 / 조은 1993) 중 **1편**을 고른다.

1. **논증의 재구성** — 그 논문의 주장·근거·방법을 내 말로 다시 세운다(정확성).
2. **적용 대상** — 그 논증을 다른 대상(다른 지역·시기·사물·집단)에 적용한다. 대상은 구체적일수록 좋다(예: 김백영의 '이중적 개념화'를 일제기 광주·목포에; 조은의 '단위 전환'을 우리 집 3대에; 이용기의 '전통의 재편'을 내 고향의 향교·문중에).
3. **적용의 결과** — 무엇이 보였고, 어디서 삐걱대는가. 삐걱대는 지점이 곧 사건·우연의 자리다("인과성과 우연성은 상호 대립적이지 않다" — 채오병·전희진).
4. **한계** — 이 적용이 말할 수 없는 것 하나. 자료가 없어서인가, 논증의 범위 밖이어서인가.

**채점**: ① 빌린 논증을 정확히 재구성했는가 ② 적용 대상이 구체적인가 ③ 가능성과 한계를 함께 제시했는가 ④ 문장.
