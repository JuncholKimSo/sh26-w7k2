# 아카이빙 계획서 (4주 2회차 제출, 실습 ①)

1. **수집 대상** — 시드 자료에서 고른 주제 한 줄(예: "광장의 발언에 나오는 '집'·'월세'"). 왜 이 주제인가 두 문장.
2. **목표 자료의 유형과 시기** — 법령 / 통계 / 공문서 / 신문 / 사진·지도 / 구술 / 발언 중 어떤 것을, 어느 시기(조선 후기 / 식민지 / 개발연대 / 현재)에서 찾을 것인가.
3. **어느 DB에서** — 7부 DB 중 최소 3곳(하나의 DB에 의존하지 말 것).
4. **찾은 자료 5건** — 자료 메모 5요소(서지 / 핵심 내용 / 발췌 / 내 주제와의 관계 / 의문)로. 반 공동 자료 목록 양식(CSV)에도 기입.
5. **못 찾은 것 1건** — 무엇을 어디서 찾았는데 없었나. 왜 없다고 생각하나("자료의 부재도 자료이다").
6. **해석 한 단락** — 찾은 자료 5건이 함께 말하는 것 하나.
7. **인용 규범** — 출처·수정일·접속일. 시드 발언은 ID로, 재식별 금지.
