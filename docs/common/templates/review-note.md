# 논문 리뷰 (강독 논문 1편당 — 분량은 중요하지 않다)

> 리뷰: 간략하게 이 논문의 요점이 무엇이며, 의미가 무언지 적는다. 특히 이해가 안 되는 경우 어디가 이해 안 되는지 적는다. 분량은 중요하지 않다. 아래 5요소는 그 길잡이다.

**학번 · 이름 · 주차 · 논문(저자 연도)**

1. **서지** — 저자(연도), 「제목」, 『학술지』 권(호), 쪽. 강독 논문 묶음 PDF pp.NN~NN. 접속일(온라인 열람 시).
2. **핵심 주장** (2~4문장) — 네 물음으로:
   - 무엇을 관찰했나 (자료·대상·시기)
   - 시선은 어디에 있나 (국가 / 지역 / 개인·신체 — 누구 편에서 보는가)
   - 무엇에 엄격한가 (방법·자료 비판·개념 정의)
   - 글쓰기 구조는 (문제 → 자료 → 분석 → 주장의 순서)
3. **발췌** — 가장 중요한 문장 1~2개, 쪽수 포함. 원문 그대로.
4. **내 관심(기말 주제)과의 관계** — 이 논문의 논증·자료 중 내 주제에 빌려 쓸 것 하나.
5. **의문 하나** — 다 이해했다는 확인이 아니라 **어디가 이해 안 되는지**. 수업은 여기서 시작한다.

---
**짝의 긴장** (한 문장) — 이번 주 두 논문은 어디서 부딪히는가.
**격자의 자리** — 시간축(조선 후기 / 식민지 / 해방~개발연대 / 민주화 이후~현재) × 스케일축(글로벌 / 국가 / 지역 / 신체·일상) 어느 칸인가. 두 칸에 걸치면 걸치게.
