## 없는 것 / 미비한 것
- 강의안에 적힌 보조 지표(농가인구 비율·산업별 취업자, 수출액·경제성장률, 1인가구·혼인율·노인빈곤율, GRDP·순이동, 집회·시위 건수·시민단체 수)는 이번 5세트에 넣지 않았다: 각 자리의 대표 지표 하나씩만. 필요하면 같은 양식으로 폴더를 추가한다.
- 4번은 추계인구 기준이라 주민등록 기준(2019년 50% 돌파 보도)과 소수점 아래에서 다르다. 이 차이를 시연에서 '조사통계 vs 보고통계'의 예로 쓴다.
- 5번은 선관위 원자료와 대조 전이다. 대조 후 README '알려진 문제'와 수정일을 갱신할 것.
- 재생성 스크립트: 세계은행 API·e-나라지표 표를 다시 받아 그리는 파이썬 스크립트는 저장소 밖(교수 로컬)에 있음. 접속일이 바뀌면 각 README의 수집일도 함께 고칠 것.
