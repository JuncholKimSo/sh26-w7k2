# 03 가족주의·사회재생산 — 합계출산율 (한국·일본, 1960~2024)

- **주차 / 쓰임**: week03 — 1회차 3절 셋째 자리(가족주의 / 사회재생산). 1983년(대체출산율 2.1 하회)·2018년(1.0 하회) 두 문턱을 세로선으로 표시.
- **출처**: World Bank, World Development Indicators, 지표 `SP.DYN.TFRT.IN` (Fertility rate, total, births per woman). 한국 원자료는 통계청 「인구동향조사」(KOSIS 인구 > 인구동향조사 > 출생 > 합계출산율). API: https://api.worldbank.org/v2/country/KOR;JPN;GBR/indicator/SP.DYN.TFRT.IN?format=json&per_page=300&date=1960:2024
- **원자료 판·수집일**: 2026-08-19 API로 내려받음. 요청 범위는 1960~2024이며 2024년 값(한국 0.748)까지 들어 있음(과제 지시 1960~2023보다 한 해 더 있음 — 그대로 둠).
- **추출·정제 방법**: World Bank API(JSON) → `csv` 모듈로 그대로 옮김. 반올림 없음.
- **정제 상태**: **원본 그대로**(세계은행 값 무수정) — 인용 가능. 단, 통계청 공식 확정치와 소수 셋째 자리에서 다를 수 있음(세계은행은 UN 추계로 보정하는 해가 있음) — 기말 인용 시 KOSIS 값으로 한 번 대조 권장.
- **열 설명**: `연도` — `국가` — `국가코드` — `합계출산율_명`(여성 1명이 가임기간에 낳을 것으로 기대되는 평균 출생아 수) — `지표코드` — `source_url` — `retrieved`. 결측은 빈칸(없음).
- **이용 범위**: 수업 내 사용·기말 인용 가능(출처 명기 시). 라이선스 CC BY 4.0.
- **알려진 문제**: (1) 1960~70년대 한국 값은 센서스·표본조사로 역추계한 값 — 인구동향조사(출생신고 기반)의 연속 시계열은 1970년부터. (2) 합계출산율은 '기간' 지표라 출산 연기(만혼)를 실제 무자녀와 구별하지 못함 — 코호트 출산율은 다르게 움직인다. (3) 일본 1966년의 급락(1.58)은 병오년(丙午) 미신 효과 — 통계는 문화를 기록한다.
- **수정일**: 2026-08-19

## 그림이 보여주는 것 / 못 담는 것
- **보여주는 것**: 한국은 1960년 6.0명에서 1983년 2.06명으로 대체수준 아래로, 2018년 0.98명으로 1명 아래로 내려갔고 2024년 0.75명 — 일본(1.15)과 1980년대 중반까지는 겹치다가 2000년대 이후 아래로 갈라진다. 출산 억제 정책 시대의 성공과 그 이후의 반전이 한 선에 있다.
- **못 담는 것**: 통계의 '가구'와 '출생'을 누가 어떻게 정의했나(호적→주민등록, 혼외 출생의 등록), 그리고 아이를 낳지 않는 결정이 만들어진 자리 — 노동시간·주거·돌봄의 배치는 이 선에 없다. 노인빈곤율을 옆에 놓으면 다른 이야기가 된다.
