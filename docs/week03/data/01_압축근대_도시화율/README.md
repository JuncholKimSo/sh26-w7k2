# 01 압축근대 — 도시인구 비율 (한국·일본·영국, 1960~2024)

- **주차 / 쓰임**: week03 — 1회차 3절 '개념 다섯 자리를 통계로' 첫 자리(압축근대). 카드 "압축근대"에 얹는 첫 숫자. 비교선(일본·영국)은 '압축'이 상대적 개념임을 보이기 위한 것.
- **출처**: World Bank, World Development Indicators, 지표 `SP.URB.TOTL.IN.ZS` (Urban population, % of total population). 원자료는 UN World Urbanization Prospects(각국 통계기관의 '도시' 정의를 그대로 씀). API: https://api.worldbank.org/v2/country/KOR;JPN;GBR/indicator/SP.URB.TOTL.IN.ZS?format=json&per_page=300&date=1960:2024
- **원자료 판·수집일**: 2026-08-19 API로 내려받음(WDI 최신 갱신판). `series.csv`의 `retrieved` 열과 동일.
- **추출·정제 방법**: World Bank API(JSON) → 파이썬 `csv` 모듈로 그대로 옮김. 반올림·보간 없음. 그림은 matplotlib.
- **정제 상태**: **원본 그대로**(세계은행 값 무수정) — 인용 가능.
- **열 설명**: `연도`(서기) — `국가`(한국·일본·영국) — `국가코드`(ISO3) — `도시인구비율_퍼센트`(총인구 중 도시 거주 인구, %) — `지표코드` — `source_url` — `retrieved`(접속일). 결측은 빈칸(이번 자료엔 없음).
- **이용 범위**: 수업 내 사용·기말 인용 가능(출처 "World Bank WDI, SP.URB.TOTL.IN.ZS, 접속 2026-08-19" 명기 시). 라이선스 CC BY 4.0.
- **알려진 문제**: (1) '도시'의 정의가 나라마다·시기마다 다르다(한국은 읍·동 기준 vs 시 지역 기준이 통계마다 다르며, KOSIS 인구총조사의 '도시화율'과 수치가 다를 수 있음). (2) 행정구역 개편(1986 광주직할시 승격, 1988 광산군 편입, 1995 도농통합 등)이 도시 인구를 한꺼번에 바꾼다 — 곡선의 일부는 사람이 아니라 경계가 움직인 것. (3) 센서스 사이 연도는 추계값.
- **수정일**: 2026-08-19

## 그림이 보여주는 것 / 못 담는 것
- **보여주는 것**: 한국은 1960년 27.7%에서 1990년 74.0%로 30년 만에 46%p 올랐다 — 같은 기간 일본은 63→77%, 영국은 이미 78% 언저리에서 거의 움직이지 않았다. 서구가 100년 넘게 그린 곡선을 한 세대에 그린 기울기, 그것이 '압축'이다.
- **못 담는 것**: '도시'의 정의 변경(행정구역 개편, 1988 광주 광산군 편입 같은 것)이 곡선을 얼마나 밀어올렸는지, 그리고 이촌향도를 겪은 사람의 시간 — 도시 안에서 어떻게 살았는지는 이 선에 없다.
