# 02 발전 — 1인당 GDP (한국·일본, 1960~2024, 선형축·반로그축)

- **주차 / 쓰임**: week03 — 1회차 3절 둘째 자리(발전)와 2절 '시각화 규범'의 **반로그축 시연**. 같은 데이터를 `chart_linear.png`와 `chart_log.png` 두 장으로 그려 축이 서사를 바꾸는 것을 보인다.
- **출처**: World Bank, World Development Indicators, 지표 `NY.GDP.PCAP.KD` (GDP per capita, constant 2015 US$). 원자료는 각국 국민계정(한국은 한국은행 ECOS). API: https://api.worldbank.org/v2/country/KOR;JPN;GBR/indicator/NY.GDP.PCAP.KD?format=json&per_page=300&date=1960:2024
- **원자료 판·수집일**: 2026-08-19 API로 내려받음. `series.csv`의 `retrieved` 열과 동일.
- **추출·정제 방법**: World Bank API(JSON) → 파이썬 `csv` 모듈로 그대로 옮김. 반올림 없음. 영국(GBR)도 API로 받았으나 그림·CSV에는 한국·일본만 담음.
- **정제 상태**: **원본 그대로**(세계은행 값 무수정) — 인용 가능.
- **열 설명**: `연도` — `국가` — `국가코드` — `1인당GDP_2015불변USD`(2015년 가격 기준 미국 달러) — `지표코드` — `source_url` — `retrieved`. 결측은 빈칸(없음).
- **이용 범위**: 수업 내 사용·기말 인용 가능(출처 명기 시). 라이선스 CC BY 4.0.
- **알려진 문제**: (1) '불변 달러'는 각국 GDP 디플레이터와 2015년 환율로 환산한 값 — 구매력(PPP) 기준이 아니므로 생활수준 비교에는 한계. (2) 한국은행 기준연도 개편(2015→2020 등)마다 과거 시계열이 소급 수정되므로 내려받은 날짜에 따라 값이 다를 수 있음. (3) 1953년 이전·1960년 이전은 이 지표에 없음(강의안의 '1953~'는 한국은행 ECOS·KOSIS 국민계정에서 따로 받아야 함). (4) 1998년(외환위기)의 하락이 선형축에서는 거의 안 보임.
- **수정일**: 2026-08-19

## 그림이 보여주는 것 / 못 담는 것
- **보여주는 것**: 한국의 1인당 GDP는 1960년 1,038달러(2015년 가격)에서 2024년 37,048달러로 36배 — 반로그축에서 1960~1990년대의 기울기(연 성장률)가 일본보다 가파르고, 2020년대에 두 선이 거의 붙는 것이 보인다. 선형축은 '기적'을, 반로그축은 '기울기의 차이'를 말한다 — 축이 서사다.
- **못 담는 것**: 발전이 치운 사람들 — 부랑인 단속 건수, 시설 수용자 수, 산업재해, 소득 분배는 이 선 어디에도 없다(10주 예고). 평균은 분포를 지운다.
