# 05 민주주의·시민사회: 대통령선거·국회의원선거 투표율 (1948~2025)

- **주차 / 쓰임**: week03: 1회차 3절 다섯째 자리(민주주의 / 시민사회). '광장의 크기'를 숫자로 재는 가장 흔한 지표. 12주·기말 시드 자료("누가 말했는가")로 이어지는 자리.
- **출처**: 원자료는 중앙선거관리위원회 선거통계시스템(https://info.nec.go.kr → 투표율 → 역대 선거 투표율). 이 CSV의 수치는 **위키백과 정리표에서 옮긴 2차 자료**임: 대통령선거: https://ko.wikipedia.org/wiki/대한민국의_대통령_선거 '역대 대통령 선거' 표(투표율 열); 국회의원선거: 「대한민국 제N대 국회의원 선거」 각 문서(제헌~제22대) 정보상자의 '투표율' 항목. 위키백과 표는 선관위 수치를 옮긴 것으로 보이나 **검증 필요**(아래).
- **원자료 판·수집일**: 2026-08-19 위키백과 위키텍스트(action=raw)에서 정규식으로 추출. 선관위 시스템은 자바스크립트 화면이라 키 없이 자동 수집이 되지 않아 수치 대조는 아직 하지 않았음.
- **추출·정제 방법**: 위키텍스트의 투표율 값(소수 첫째 자리 %)을 그대로 옮김. 대통령 **간선**(1948 제1대, 1960.8 제4대, 1972 제8대·1978 제9대·1979 제10대·1980 제11대·1981 제12대)은 투표율이 없어 제외했고 그림에서 선을 끊음. 1960년 3월 15일 제4대 대선(97.0%)은 부정선거로 무효화되었으나 값은 남겨 두고 비고에 표시. 제5대 총선(1960)은 민의원 84.3%(참의원 84.1%). 2025년 제21대 대선(79.4%)은 과제 범위 1948~2024 밖이지만 있는 값이라 넣음.
- **정제 상태**: 부분 정제: **2차 자료·검증 필요**. 기말에 인용하려면 info.nec.go.kr 또는 『역대 선거 통계』(선관위 간행)에서 값을 대조하고 그쪽을 출처로 적을 것.
- **열 설명**: `연도`: `선거일`(YYYY-MM-DD), `선거종류`(대통령선거(직선) / 국회의원선거), `대수`, `투표율_퍼센트`(투표자 ÷ 선거인 × 100), `비고`, `출처`, `retrieved`. 결측은 행 자체를 두지 않음(간선 대선).
- **이용 범위**: 수업 내 사용 가능. 기말 인용은 선관위 값으로 대조한 뒤에(위키백과 자체는 인용 출처로 쓰지 않는다).
- **알려진 문제**: (1) 2차 자료: 위키백과 표는 편집자가 옮긴 값이라 오탈자 가능(특히 1950년대). (2) 선거인 명부의 정확도가 시기마다 다르다, 1950~60년대의 90%대 투표율은 동원·부정(3·15)·명부 부풀림이 섞여 있어 '참여'로 읽으면 안 된다. (3) 지방선거·재보궐·국민투표는 넣지 않았음. (4) 총선 투표율은 지역구 기준이며 2004년 이후 비례대표 투표율과 미세하게 다를 수 있음.
- **수정일**: 2026-08-19

## 선관위 원자료로 다시 받는 절차
1. https://info.nec.go.kr 접속 → 상단 메뉴 「투표율」 → 「역대 선거 투표율」(또는 「투표율 분석」) → 선거종류(대통령선거 / 국회의원선거) 선택 → 선거명 선택 → 조회 → 표 하단 '엑셀 저장'.
2. 1948~1980년대 초 값은 선관위 간행 『대한민국 선거사』 제1~2집·『역대 국회의원 선거 상황』(국회도서관 원문 제공)에서 확인.
3. 이 CSV의 `투표율_퍼센트`와 대조해 다른 값이 있으면 이 README '알려진 문제'에 적고 `수정일`을 갱신.

## 그림이 보여주는 것 / 못 담는 것
- **보여주는 것**: 투표율은 1950년대 90%대에서 장기 하락해 2000년대 후반 바닥(2007 대선 63.0%, 2008 총선 46.1%)을 찍고 2010년대 이후 되올랐다: 1987년 대선(89.2%)이 민주화 국면의 봉우리이고, 유신~5공(1972~1987)은 대통령 투표율 자체가 없다(간선). '없음'이 그 시대의 정치를 말한다.
- **못 담는 것**: 광장에서 **누가** 말했는가: 투표율은 참여의 크기만 재고 누가 어떤 말을 했는지, 투표 밖의 광장(집회·시위·청원·발언 신청)을 재지 않는다(12주·기말 시드 자료의 자리). 1950~60년대의 높은 투표율은 '동원'과 '참여'를 구별하지 못한다.
