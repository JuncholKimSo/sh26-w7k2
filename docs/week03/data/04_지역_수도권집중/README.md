# 04 지역·중심-주변: 수도권 인구 비중 (1970~2024)

- **주차 / 쓰임**: week03: 1회차 3절 넷째 자리(지역 / 중심-주변). 전국 인구 중 수도권(서울·인천·경기) 비중 한 선. 2회차 실습에서 학생이 KOSIS에서 같은 표를 직접 열어 보는 예제이기도 함.
- **출처**: e-나라지표(index.go.kr) 지표 1007 「지역별 인구 및 인구밀도」, 통계표 100701: https://www.index.go.kr/unity/potal/main/EachDtlPageDetail.do?idx_cd=1007 . e-나라지표의 원자료: 국가데이터처(구 통계청) 「장래인구추계 시도편: 2022~2052」(2024년 작성, 7월 1일 기준 **추계인구**, 단위 천 명). 관련 KOSIS 통계표: 인구 > 장래인구추계 > 시도별 장래인구추계 > 「주요 인구지표(성비, 인구성장률, 인구구조, 부양비 등)/시도」 및 「시도별 추계인구(1세별, 5세별)」.
- **원자료 판·수집일**: 2026-08-19, e-나라지표 통계표 페이지(`showStblGams3.do?stts_cd=100701&idx_cd=1007&freq=Y&period=1960:2024`)에서 HTML 표를 그대로 읽음(로그인·API 키 없이 공개). 표는 1970년부터 시작함(1960년대 없음).
- **추출·정제 방법**: 표의 '인구' 열만 옮기고(인구밀도 열 제외), 계·서울·경기·인천·수도권 행을 취함. **수도권비중_퍼센트 = 수도권 ÷ 계 × 100 (소수 둘째 자리 반올림)은 이쪽에서 계산한 파생값**이며 원표에는 없음. 나머지 숫자는 원표 그대로.
- **정제 상태**: 부분 정제(원값 그대로 + 파생 비율 1열): 인용 가능. 단, 인용 시 "추계인구 기준"임을 밝힐 것.
- **열 설명**: `연도`: `전국`(천 명), `서울`(천 명), `경기`(천 명; 1970~1980년은 인천 포함), `인천`(천 명; 1981년 직할시 승격 이후만, 그 전은 빈칸 = 경기에 포함), `수도권`(천 명 = 서울+인천+경기, 원표 값), `수도권비중_퍼센트`(파생), `출처`, `retrieved`. 결측은 빈칸.
- **이용 범위**: 수업 내 사용·기말 인용 가능(출처 명기 시). e-나라지표·KOSIS 자료는 공공누리 제1유형(출처 표시).
- **알려진 문제**: (1) 이 표는 **추계인구**(센서스 기반 보정, 7월 1일 기준)이지 주민등록인구(12월 31일, 등록 기준)도 인구총조사 원값도 아니다: 세 통계의 수도권 비중은 소수점 아래에서 다르며, 주민등록 기준으로는 2019년에 이미 50%를 넘었다고 보도됨. 이 차이 자체가 3주 개념 '조사통계 vs 보고통계', 14번 개념 '등록'의 실증. (2) 1981 인천 직할시·1989 이후 경기 시 승격 등 행정구역 개편은 수도권 합계에는 영향이 없으나 시도별 열에는 단절이 있음. (3) 1960년대(이촌향도의 초기)가 표에 없음, 1949·1955·1960·1966년 인구총조사로 채우려면 KOSIS 「인구총조사 > 시도/성/연령별 인구」(1925~)를 별도로 받아야 함.
- **수정일**: 2026-08-19

## KOSIS에서 다른 기준으로 다시 받는 절차(2회차 실습용)
1. kosis.kr 접속 → 상단 검색창에 「행정구역(시군구)별 주민등록인구」 또는 「주민등록인구현황」 입력 → 통계표 「행정구역(시군구)별, 성별 인구수」(행정안전부, 1992~ 월/연) 선택.
2. 조회 설정: 시점 = 연(1992~2025), 행정구역 = 전국·서울특별시·인천광역시·경기도, 항목 = 총인구수 → 조회 → 다운로드(CSV/XLSX).
3. 인구총조사 기준으로 1949년부터 보려면: 「인구총조사 > 인구부문 > 총조사인구(1925~2010) > 시도/성/연령별 인구」 → 시도 = 전국·서울·경기(1981년 이전 인천은 경기에 포함) → 5년 간격 값.
4. 두 기준(주민등록 vs 총조사 vs 추계)의 수도권 비중을 한 표에 나란히 놓고 "왜 다른가"를 첫 질문으로 삼는다.

## 그림이 보여주는 것 / 못 담는 것
- **보여주는 것**: 수도권 비중은 1970년 28.3%에서 1990년 42.8%, 2000년 46.3%, 2020년 50.2%로 올라 인구의 절반이 국토의 12%에 산다: 1970~1990년의 기울기가 가장 가파르고 2000년대 이후 완만해진다.
- **못 담는 것**: 광주·전남 안의 격차(광주 vs 군 지역), 지역 안에서 누가 떠나고 누가 남았는가(연령·성별 순이동), 그리고 GRDP가 못 재는 마을의 '발전'(11주 예고). 하나의 비율은 '수도권 아닌 곳'을 한 덩어리로 만든다.
