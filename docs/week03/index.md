# 3주 — 개념을 세어 보고 그려 보기 — 통계로 재점검

## 질문
2주 카드는 느낌인가 사실인가. 통계는 어디서 왔고, 어느 지표를 고르느냐가 왜 곧 주장인가.

## 읽을 것
- 박명규·서호철(2003), 『식민권력과 통계』 — 발췌("통계는 어디서 왔나")
- [../common/guides/statistics-guide.html](../common/guides/statistics-guide.html) — 조사통계/보고통계·표준분류·KOSIS 경로

## 수업의 순서 (100분 × 2회)
- 1회차 — 통계는 어디서 오는가(15) → **교수 시연 다섯 자리**(60): 압축근대→도시화율 / 발전→1인당 GDP / 가족→출산율 / 지역→수도권 집중 / 민주주의→투표율, 자리마다 '보여주는 것 / 못 담는 것' → 시각화의 문법(10)
- 2회차 — 실습(55): 각자 개념 하나를 KOSIS 지표로 그린다 → 그림 비평(25) → 제출

## 이 주의 자료(교수 제공)
- [data/01_압축근대_도시화율/](data/01_압축근대_도시화율/) … [data/05_민주주의_투표율/](data/05_민주주의_투표율/) — 교수 시연 5세트(CSV·그림·README: 출처·정제 상태·보여주는 것/못 담는 것)
- [data/indicator_hints.html](data/indicator_hints.html) — 개념별 지표 힌트표(실습용)
- [../workshop-stats/index.html](../workshop-stats/index.html) — 통계연감 지면 뷰어(광주·전남 면적·광공업, 인용 불가 상태) — 1988년 광주 면적 208→501㎢가 무엇인지 보라

## 실습 방안
- **실습 방안(2회차 55분)** — ① 개념 하나 고르기(2주 카드) → ② 힌트표에서 지표 후보 2개 → ③ KOSIS에서 시계열 내려받기(연도·값·출처 URL을 CSV로) → ④ 꺾은선 1장(축 시작점·단위 명기) → ⑤ 변곡점 하나에 동그라미, 그 해 무슨 일이 있었나 한 줄 → ⑥ 세 문장. 두 지표를 골라 반대 이야기가 나오면 더 좋다.
- **흔한 함정** — 기준연도 개편(GDP), 행정구역 개편(도시화율·지역 인구), 조사통계 vs 보고통계의 차이(같은 '인구'가 두 개), 0과 결측의 차이.

## 과제
- **실습 ① 3주분**: 그림 1장 + 변곡점 표시 + 문장 3개("보여주는 것 / 못 담는 것 / 다른 지표를 고르면") → 폼
- 4주 준비: 「역사·사회 연구를 위한 디지털 자료 찾기」([../common/guides/digital-sources.html](../common/guides/digital-sources.html))를 읽어 온다. 노트북 지참
