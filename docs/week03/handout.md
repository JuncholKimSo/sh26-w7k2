# 3주 — 개념을 세어 보고 그려 보기: 개념은 숫자로 확인되는가, 그리고 숫자가 못 담는 자리는 어디인가

## 1. 질문
2주에 받은 개념 지도의 각 자리는 숫자로 확인되는가. '압축근대'는 도시화율 곡선 위에서, '발전'은 GDP 시계열 위에서, '가족주의'는 출산율 위에서 어떤 모습인가 — 그리고 **통계가 개념을 못 담는 자리는 어디인가.** 세어야 할 것은 논문이 아니라 사회다. 통계는 중립적 배경이 아니라 국가가 만든 지식이고, 어느 지표를 고르느냐가 곧 주장이다. 관통 질문("지금 현재 일상의 구조적 형성")에 답하려면 숫자와 숫자의 공백을 둘 다 읽어야 한다. 그 공백이 4주에 자료를 찾으러 가는 자리다. (강독 짝은 없다. 교재는 박명규·서호철 2003 『식민권력과 통계』.)

## 2. 개념
- **통계 = 국가의 지식** — statistics는 state에서 왔다. "통계는 근대국가의 형성에 발맞추어 생겨난, 사회에 대해 양화된 정보를 얻어내는 근대국가와 행정의 한 장치"(박명규·서호철 2003). 양화는 질적인 차이의 무시를 전제로 한다.
- **조사통계 vs 보고통계** — 직접 세는 것(센서스·국세조사)과 행정 보고를 모은 것(업무통계·통계연보). 같은 '인구'라도 출처가 다르면 수가 다르다(박명규·서호철 2003).
- **표준분류와 시계열 단절** — 산업·직업 분류가 바뀌면 시계열이 끊긴다. 분류는 집단을 만들고(부르디외·샤르티에 2019), 분류 범주 자체가 역사적 산물이다 — 1909~10년 민적조사에서 '양반'은 직업이었다.
- **장기추계 논쟁** — 매디슨 프로젝트, 낙성대경제연구소 장기통계. 식민지기 GDP 추계 자체가 식민지 근대화론 논쟁의 무기였다. 통계는 논쟁의 당사자다.
- **어느 지표를 고르느냐가 곧 주장이다** — GDP로 보면 기적, 노인빈곤율로 보면 파탄. 같은 시대다.
- **통계가 없는 자리가 개념의 자리다** — 부랑인 수용자의 수, 광장의 발화자, 마을의 '발전', 기억. 부재에는 두 종류가 있다: 안 센 것과 세고도 안 보여준 것.
- **시각화 규범** — 꺾은선(시간)·막대(비교)·단계구분도(공간)·반로그(성장률). 모든 그림에 "보여주는 것 / 숨기는 것" 두 문장을 붙인다. 리뷰 노트·기말 원고까지 유지.

## 3. 세부 내용 — 수업의 순서
**수업 전에** — KOSIS(kosis.kr) 계정을 만들고 통계표 하나를 미리 열어 본다. GitHub `common/통계_안내.md`(통계는 어디서 오는가)와 `week03/`의 개념별 지표 힌트표를 훑어 둔다. 교수 시연 차트 5세트는 수업 전에 `week03/`에 올라간다. 2회차에는 노트북(스프레드시트가 열리는 것)을 가져온다.

**1회차 (100분) — 개념을 통계로 다시 보기 (교수 시연)**
1. 들어가며 — 격자에 숫자를 얹으면 (10분) — 2주 격자를 다시 띄우고 카드 하나("압축근대")를 집는다. 이 카드는 느낌인가 사실인가, 사실이라면 어떤 숫자가 그것을 보여주는가. 오늘은 카드마다 그것을 떠받치거나 흔드는 통계 하나를 얹는다.
2. 통계는 어디서 오는가 (15분) — 조사통계/보고통계, 1차·2차 통계, 국가기본통계, 표준분류, 장기추계 논쟁, 통계의 부재를 압축 안내한다. KOSIS 화면을 띄우기 전에 『식민권력과 통계』의 첫 물음 세 개를 같이 던진다: 누가 왜 세었나, 얼마나 믿을 만한가, 어디에 쓰였나.
   > 📖 박명규·서호철 2003 (p.5~6) "'통계(statistics)'란, 그 말 자체가 이미 '국가(state; Staat)'라는 어휘와 밀접한 관련을 드러내고 있듯이, 본래 응용수학의 한 분야나 경험적 자료를 수집·처리하는 방법론이 아니라, 특히 국가에 대한 여러 사항들을 기술(記述)하는 것을 가리키는 말이었다. (…) 통계는 근대국가의 형성에 발맞추어 생겨난, 사회에 대해 양화(量化)된 정보를 얻어내는 근대국가와 행정의 한 장치이자, 사회의 실상과 국가의 통치활동을 기술하는 국가의 담론이었던 것이다." — "통계는 어디서 왔나"의 답: 국가.
   > 📖 박명규·서호철 2003 (p.13) "통계는 '앎(knowledge)'과 '통치(government)'가 결합한 근대국민국가 특유의 지식형태이다. (…) 추상적이고 동질적인 인민이라야 예컨대 모든 국민을 차별 없이 한 사람으로 헤아리는 근대적 센서스의 조사대상이 될 수 있었다. 양화(量化)는 질적인 차이의 통제 또는 무시를 전제로 하기 때문이다." — 시연 다섯 자리마다 "그림이 못 담는 것"을 묻는 이유.
   > 📖 부르디외·샤르티에 2019 (1장 p.36) "프랑스 국립통계연구소INSEE나 기타 기관이 생산하는 객관적 범주들 그리고 사회 집단들에도 분명한 경계가 있습니다. 여러 기관이 중간계급, 기업주, 임금노동자 등을 구분하고 분류체계를 확립하는데, 바로 이런 분류화 작업이 집단을 존재하게 만들지요. (…) 그러니까 언제나 이렇게 자문해야 합니다. 왜 하필 이런 식으로 분할이 일어나는가? 이런 식의 분할이 무엇에 쓸모가 있는가? 누구를 위해 봉사하는가?" — KOSIS 표준분류를 열 때 던질 세 질문.
   > 📖 박명규·서호철 2003 (p.107) "1909~10년 민적조사 당시 일본제국주의가 '양반'과 '유생(儒生)'을 조선인의 직업분류에 포함시켰다는 사실 (…) 조선인들의 전통적 직업명을 일본의 근대적 직업분류 속으로 포괄시키려던 1930년 국세조사의 해석학적 작업" — 표준분류가 바뀌면 시계열이 끊긴다는 원리의 원조 사례.
3. 개념 다섯 자리를 통계로 — 교수 시연 (60분, 자리당 약 12분) — 자리마다 **개념 → 통계 → 그림 → 그림이 못 담는 것** 순서로 본다.
   - **압축근대**: 도시화율 1949~2020·농가인구 비율·산업별 취업자 구성(꺾은선 3개 겹치기) — 서구가 100년 걸린 곡선을 30년에 그리는 기울기가 보인다 / 못 담는 것: 압축을 겪은 사람의 시간, 이촌향도의 생애.
   - **발전**: 1인당 GDP·수출액·경제성장률 1953~(반로그 꺾은선) — '기적' 서사 / 못 담는 것: 발전이 치운 사람들 — 부랑인 단속 건수·시설 수용자 수는 어느 통계에 있나(10주 예고).
   - **가족주의 / 사회재생산**: 합계출산율·1인가구 비율·혼인율·노인빈곤율(꺾은선+막대) — 최저출산과 노인빈곤이 한 그래프에 / 못 담는 것: 통계의 '가구'는 누가 정의했나(호적→주민등록).
   - **지역 / 중심-주변**: 수도권 인구 집중률·GRDP 광주·전남 vs 서울·순이동(단계구분도+꺾은선) — 지도는 지역을 칸으로 나눈다 / 못 담는 것: 광주·전남 안의 격차, GRDP가 못 재는 마을의 '발전'(11주 예고).
   - **민주주의 / 시민사회**: 투표율·집회·시위 건수·시민단체 수·신문 발행부수(막대·꺾은선) — 광장의 크기를 숫자로 / 못 담는 것: 광장에서 **누가** 말했는가(12주·기말 시드 자료의 자리).
   - 시연의 메시지 셋: ① 개념은 통계로 확인되기도, 반박되기도 한다 ② 통계가 없는 자리가 개념의 자리다 ③ 어느 지표를 고르느냐가 곧 주장이다.
   > 📖 박명규·서호철 2003 (p.58~59) "『통계연보』의 편제는, 총독부의 (…) 통치가 한반도 또는 조선민중 전체에 미치고 있으며, 그리하여 '조선'은 통계표 양식들이 보여 주는 그 일관되고 정연한 통치 아래에서 하나의 통일된 단위를 이루어 발전하고 있다는 것을, '사실'로 보여 주려 하는 것이다. (…) 통계, 통계표의 수치와 그래프가 양화(量化)·가시화하여 보여 주는 것은 일차적으로 성장, 발전, 진보라는 근대적 방향성이다." — 통계표의 항목 배열 자체가 하나의 서사라는 것. '어느 지표가 주장'의 원조.
   > 📖 박명규·서호철 2003 (p.59 / p.121) "『통계연보』는 식민권력에 불리한 증거들은 거의 싣고 있지 않다. 실제로 조선총독부가 여러 가지 경로로 수집한 많은 중요한 통계자료들은 '비밀'이나 '극비'로 분류되어 공간되지 않았던 것이다. / 널리 조사는 하되 공표하지는 않는, 비밀에 부쳐진 통계자료란 무척 역설적이다." — 통계의 부재 두 종류: 안 센 것과 세고도 안 보여준 것.
4. 시각화의 문법 (10분) — 꺾은선·막대·단계구분도·반로그 4종의 용도와 구조적 왜곡(축 시작점, 표본 크기 은폐, 칸 경계의 자의성). 규범 하나: 모든 그림에 "보여주는 것 / 숨기는 것" 두 문장.
5. 마무리 — 실습 예고 (5분) — 각자 2주 카드 중 개념 하나를 고른다. 다음 시간에 KOSIS에서 그 개념을 떠받치거나 흔드는 지표를 찾아 그린다.
   > 📖 박명규·서호철 2003 (p.123 / p.124~125 / p.128) "그런 통계자료들 역시 식민지 조선사회를 통계장치와 통계조사라는 '근대적' 시선을 통해 바라본 결과물일 뿐 아니라, 어디까지나 '식민권력'의 시선의 산물이기도 하다. / 국세조사를 통해 국가는 처음으로 각 주민들의 집 앞에서 그들과 직접 대면하였고, 따라서 그들을 더 이상 신분이나 가문, 지역공동체 등에 의해 차별되지 않는, 추상적이고 동질적인 '국민'으로 불러 세우는 효과를 낳았다. 주권자로서, 개별적인 권리와 의무의 주체로서 존재하기에 앞서, 일본 '국민'은 국가의 조사에 의해 성립되었던 것이다. / 근본적으로 식민지라는 조건 자체가, 조선에서 '근대적' 통계체계와 '근대적' 센서스가 총독부 측이 선전했던 그런 '근대'에 도달하는 것을 가로막고 있었던 것이다." — 1회차 마무리에 함께 읽는 맺음말. "국민은 국가의 조사에 의해 성립되었다"를 들고 실습으로 간다.

**2회차 (100분) — 개념 하나를 숫자로 재점검하기**
1. 실습 안내 (10분) — 워크숍 「디지털 자료 찾기」 프로젝트 3 "숫자 뒤의 역사"의 축소판. 절차: ① KOSIS(또는 e-나라지표·지자체 통계연보)에서 고른 개념의 **시계열 지표 1개**를 고른다 — 최소 20년 이상 ② 꺾은선/막대/단계구분도 중 하나로 그린다(스프레드시트 차트면 충분) ③ **변곡점 하나**를 찍고 그 시점에 무슨 일이 있었는지 한 문장(1997, 1980, 1962…) ④ "보여주는 것 / 숨기는 것" 두 문장 + "이 개념에서 통계가 못 담는 것은 무엇인가" 한 문장. 개념별 지표 힌트: 압축근대→도시화율·농가인구 / 발전→GDP·수출 / 가족→출산율·1인가구·혼인 / 규율·복지→시설 수·수급자 수·의료보험 적용률 / 지역→수도권 집중률·순이동·GRDP / 민주주의→투표율·집회 건수 / 젠더→여성 경활률·임금격차 / 인구·등록→주민등록 인구 vs 센서스 인구 차이 / 기억→통계 없음 — 그 없음을 쓴다.
2. 실습 (55분) — 각자 그린다. 순회하며 묻는 것은 두 가지뿐이다: "그 지표는 조사통계인가 보고통계인가, 누가 만들었나?" / "0이거나 없는 연도는 그 일이 없었던 건가, 안 센 건가?" — 후자가 4주 "자료의 부재도 자료이다"의 예습. 30분 지점에 가장 뜻밖의 변곡점 하나씩 짧게 공유한다.
3. 그림 비평 (25분) — 5~6명의 그림을 띄우고 반이 함께 읽는다: ① 그림만 보고 무엇이 보이나 → ② 작성자의 세 문장 → ③ "숨기는 것"에 반이 하나씩 더 보탠다. 같은 개념에 다른 지표를 고른 두 그림이 반대 이야기를 하는 장면, 통계 없는 개념을 고른 사람이 무엇을 대신 찾았나, 1997·1980·1961의 변곡점이 여러 그림에 동시에 찍히는 것 — 사회사의 시대구분이 숫자에서 다시 나온다. 이 그림들이 4주 자료 실습·강독 리뷰 노트·기말 원고의 시각화 원칙이다.
4. 제출 (10분) — 그림 1 + 변곡점 1 + 문장 3을 **과제 제출 폼**(https://forms.gle/9qDjkpWd9wg7fgbX6)으로 낸다(실습 ① 3주분). 반 전체 그림은 GitHub `week03/gallery/`("개념의 통계 지도")에 모아 2주 격자 옆에 나란히 둔다.
