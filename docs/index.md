# 한국사회사 (2026학년도 2학기)

<p style="text-align:center; font-size:1.25em; margin:1.2em 0;"><strong>자료로 사회를 말하는 연습.</strong></p>

<p style="text-align:left;">지금 현재 우리 일상은 어떻게 만들어졌는가. 두부의 '신선함', 주민등록증, 아파트, 시험, 시간표, 광장의 발언. 오늘의 사물·제도·감각은 조선·식민지·개발연대·민주화 이후의 지층이 쌓이고 뒤엉켜 만들어졌다. 사회사는 그 지층을 <strong>자료</strong>로 읽는 학문이다.</p>

## 제출
* 모든 과제는 하나의 폼으로 낸다 → <https://forms.gle/9qDjkpWd9wg7fgbX6>
* 실습 ① (2·3·4주) — 각 주 2회차 종료 후
  - 2주 「개념 격자 만들기」: 격자 사진 1장 + 여백 질문 한 줄
  - 3주 「시각화와 설명하기」: 그림 1장 + 변곡점 + 세 문장
  - 4주 「자료 찾아 컬렉션 만들기」: 자료 5건 + 못 찾은 것 1건 + 아카이빙 계획서 ([양식](common/templates/archiving-plan.html))
* 논문 리뷰 (5~7·9~12주) — **그 주 1회차 수업 전**
  - 강독 논문 각각: 요점·의미·이해 안 되는 곳 ([양식](common/templates/review-note.html))
* 미니 논증 (8주, 중간 대체) — 8주 1회차 수업 시작 시 (+출력본 1부)
  - 강독 논문 1편의 논증을 다른 대상에 적용, A4 2매 ([양식](common/templates/mini-argument.html))
* 기말 원고 「우리 일상의 미래」 (15주) — 15주 2회차 (+출력본 1부)
  - A4 4~5매, 시드 + 직접 확보 자료 + 강독 논문 2편 이상 ([양식](common/templates/final-paper.html))
* 파일명: `학번_이름_NN주_과제명.pdf` (예: `20260000_홍길동_05주_리뷰.pdf`). PDF 권장.
* 지각 제출은 감점, 리뷰 미제출 1회는 최저 1회 제외로 흡수.
* 인용: 출처·접속일 명기. 시드 자료는 정제본만, 발언 ID로 인용, 재식별 금지 ([시드 자료 규칙](common/guides/seed-data-rules.html)).
* 문의: 수업 후 또는 이메일.

## 규칙
* 리뷰는 수업 전 제출 — 논문의 요점이 무엇이며 의미가 무언지 간략히, 이해 안 되는 곳은 어디인지 적는다. 분량은 중요하지 않다.
