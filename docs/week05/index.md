# 5주: 강독① 사회: '사회'라는 말은 어디서 왔는가

## 질문
* '사회'는 130년 된 번역어다.
* 개념이 정착한다는 것과 그 개념이 가리키는 것이 실현된다는 것은 같은가.
* 규칙: 정착 ↔ 경합.
