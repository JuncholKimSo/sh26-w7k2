# 15주 — 다시, 사회사의 쓸모 돌아보기

## 질문
* 자료가 사료가 되는 순간을 본다.
* 2주의 격자를 다시 붙여 무엇이 옮겼는지 본다.
* 그리고 묻는다 — 2026년 이 교실에서 사회사는 무슨 쓸모가 있었나.

## 읽을 것
* 김원(2005) 「사회운동의 새로운 구성방식에 대한 연구 — 2002년 촛불시위」 — 묶음 pp.582~610
* 강성현 외(2013) 「한국 사회사·역사사회학의 미래를 말하다」 — 묶음 pp.611~661
* 강독 논문 묶음 PDF: <https://drive.google.com/file/d/1JTZAFwwQwcZfXESobqQDjXrQjoHmOW_T/view?usp=drive_link> · [쪽 지도](../common/readings.html)
