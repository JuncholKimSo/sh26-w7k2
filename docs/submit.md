## 규칙
- **파일명**: `학번_이름_NN주_과제명.pdf` (예: `20260000_홍길동_05주_리뷰노트.pdf`). PDF 권장(한글·워드도 가능).
- **마감**: 리뷰 노트는 수업 전 제출이 원칙 — 수업은 리뷰 노트의 '의문'에서 시작한다. 지각 제출은 감점, 미제출 1회는 최저 1회 제외 규정으로 흡수.
- **인용**: 출처·접속일 명기. 온라인 자료는 바뀐다 — 그래서 접속일. 시드 자료(12·3 시민발언)는 교수 정제본만 쓰고, 발언은 **발언 ID**로 인용하며 **재식별을 시도하지 않는다** ([시드 자료 규칙](common/guides/seed-data-rules.html)).
- **생성형 AI**: 사용 가능하되 사용 내역(어디에 어떻게)을 끝에 명시한다.
- 문의: 수업 후 또는 이메일.
