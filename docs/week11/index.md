# 11주: 강독⑥ 광주: 지역은 어떻게 발전하였고, 우리는 그것을 어떻게 기억하는가

## 질문
* 외부에서 온 것(자본·예산·계엄군)이 지역을 통과할 때 지역 안의 균열이 드러난다: 그리고 그 균열은 기억에서 다시 갈린다.

## 읽을 것
* 1회차 지역: 박명규(1988) pp.427~458 ↔ 홍성흡(2013) pp.459~473
* 2회차 기억: 정근식(2002, 발췌 '깊이의 민주화') pp.510~553 + 최정기(2020) pp.474~509
