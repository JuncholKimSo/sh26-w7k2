# 1주 — 오리엔테이션 · 두부 한 모로 여는 사회사

## 질문
* 사회사는 왜 사회학의 방법이었고, 왜 잃었다가 되찾았는가.
* 그리고 두부 한 모로 사회를 어떻게 말하는가.

## 읽을 것
* 피터 버크, 『역사학과 사회 이론』(곽차섭 옮김, 문학과지성사 1994) 1장 「이론가와 역사가」 — 발췌 인쇄물
* 부르디외·샤르티에, 『사회학자와 역사학자』(킹콩북 2019) 1장 「사회학자의 직능」 — 발췌 인쇄물
* 김백영 외, 『사회사/역사사회학』(다산 2016) 기획의 글·1장 — 발췌 인쇄물
