# 10주: 강독⑤ 복지·보호: 복지와 '보호'는 우리에게 늘 옳은가

## 질문
* '복지'라는 말은 어디서 왔고(정근식·주윤정), 부산의 '부랑인' 수용은 국가폭력인가 지역사회의 합작인가(김일환·소준철).
* 규칙: 개념 ↔ 현장.
