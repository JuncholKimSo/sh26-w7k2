# 6주 — 강독② 근대성: 근대성은 하나인가

## 질문
근대성은 층층이 쌓이는가(김상준), 한 도시 한 순간에 동시에 작동하는가(김백영). 규칙: 이론 ↔ 사례.

## 읽을 것
- 김상준(2007) 「중층근대성: 대안적 근대성 이론의 개요」 — 묶음 pp.66~105 (1회차)
- 김백영(2006) 「식민지 도시성에 대한 이론적 탐색」 — 묶음 pp.106~150 (2회차)
- 강독 논문 묶음 PDF: <https://drive.google.com/file/d/1JTZAFwwQwcZfXESobqQDjXrQjoHmOW_T/view?usp=drive_link> · [쪽 지도](../common/readings.html)
