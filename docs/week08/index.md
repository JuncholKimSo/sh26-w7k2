# 8주: 미니 논증 워크숍 · 자료 수집 중간 점검

## 질문
* 빌린 논증은 내 대상에서 어디서 삐걱대는가: 그 지점이 곧 사건과 우연의 자리다.

## 읽을 것
* 강독 없음. 5~7주 6편 중 고른 1편을 다시 읽는다
* 김백영 외(2016) 6장 채오병·전희진 「인과성, 구조, 사건」: 발췌
