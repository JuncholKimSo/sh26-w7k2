# 중간시험 (13~14회, 10/20 · 10/22)

**회차·날짜**: 13~14회 · 10/20(화) · 10/22(목)

## 읽을 것
* 강독 없음. 5~7주 6편 중 고른 1편을 다시 읽는다
* 김백영 외(2016) 6장 채오병·전희진 「인과성, 구조, 사건」: 발췌

## 양식
* [미니 논증 양식](../common/templates/mini-argument.html)

## 과제
* **미니 논증**은 13주차까지 폼 제출(A4 3매 내외, 15점): 이 주에는 초안을 가져와 상호 독해로 다듬는다
* 9주 준비: 백승욱·이지원(2015) pp.227~267 · 정무용(2017) pp.268~304
