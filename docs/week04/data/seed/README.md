# 시드 자료 정제본 (게시 예정: 4주 1회차)

- **내용**: 12·3 내란 이후 광장의 시민발언(채록 1,333건 중 수업용 발췌)·비상행동 공개 자료의 **교수 정제본**.
- **정제 원칙**: 발언자 이름·소속·특정 장소 제거, 발언 ID 부여(`S-0001`~), 지역·날짜·형식(신청/발화)만 남김. 원본은 저장소 밖.
- **열(예정)**: 발언ID · 날짜 · 지역(서울/광주/부산…) · 광장 유형 · 발언 요지(정제) · 키워드 · 자료층(신청/발화)
- **이용 규칙**: [시드 자료 이용 규칙](../../../common/guides/seed-data-rules.html): 정제본만, ID 인용, 재식별 금지, 수업 목적 외 사용 금지.
- 정제 상태: 정제본(인용 가능, ID로) · 수정일: (게시 시 기재)
