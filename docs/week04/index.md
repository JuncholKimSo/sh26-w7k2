# 4주 — 자료는 어디에 있고, 무엇을 가져와 어떻게 쌓는가

## 질문
* 국가의 어느 손에서 나온 자료인가.
* 자료의 부재는 무엇을 말하는가.
* 그리고 지금 만들어지고 있는 자료(시드)를 어떻게 다룰 것인가.

## 읽을 것
* 자료 찾기 가이드(「역사·사회 연구를 위한 디지털 자료 찾기」) — [../common/guides/digital-sources.html](../common/guides/digital-sources.html)
* 김백영 외(2016) 7장 서호철 「사회사/역사사회학의 자료와 그 이용」 — 발췌("자료 없는 방법론이란 불모의 환상")

## 수업의 순서 (100분 × 2회)
* **1회차**
  - 원칙 5개조(15)
  - **7부 DB 시연**(45): 법령·관보 / 통계 / 공간 / 공문서 / 언론 / 생활사 / 기초·학술 DB
  - **시드 자료 배포**(20)
  - 과제 안내
* **2회차**
  - 선정(20)
  - 분류: 자료 메모 5요소·반 공동 자료 목록(25)
  - 분석: 자료에서 주장으로(15)
  - 짝짓기 규칙 소개(10)
  - **아카이빙 계획서** 실습·제출(30)

## 실습 방안
* **실습 방안**
  - ① 시드 발언에서 일상 주제 하나(집·일·학교·이동·먹는 것…)
  - ② 7부 중 3부 이상에서 그 주제의 과거 자료 5건(각 부의 '한 문장' 질문으로: 이 자료는 국가의 어느 손에서 나왔나)
  - ③ 자료 메모 5요소로 목록 CSV 기입
  - ④ 못 찾은 것 1건은 '어디서 무엇을 찾았는데 없었나'
  - ⑤ 아카이빙 계획서.
* **시드 규칙** — 교수 정제본만, 발언은 ID로, 재식별 금지.

## 과제
* **실습 ① 4주분 「자료 찾아 컬렉션 만들기」**: 자료 5건(공동 자료 목록 양식) + 못 찾은 것 1건 + 해석 한 단락 + 아카이빙 계획서 → 폼
* 5주 준비: 강독 시작 — 박명규(2001) pp.2~34 · 조계원(2016) pp.35~65. **리뷰 첫 제출**(양식 [../common/templates/review-note.html](../common/templates/review-note.html)), 1회차 수업 전
