# 4주 — 자료는 어디에 있고, 무엇을 가져와 어떻게 쌓는가: 자료 워크숍

## 1. 질문
3주에 통계가 못 담았던 것들 — 부랑인 수용자의 수, 광장의 발화자, 마을의 '발전', 기억 — 은 어디에 있는가. 법령·통계·공간·공문서·신문·사진·구술, 그리고 아직 어느 DB에도 없는 자료에 흩어져 있고, 어떤 것은 없다. 없음도 자료다. 이 주에 사회사/역사사회학의 자료를 발굴·수집·선정·분류·분석하는 방법을 한 주에 압축해 익히고, **직접 자료를 찾아낸다.** 시드 자료(12·3 시민발언 정제본)를 받고 거기서 고른 일상의 주제로 아카이빙 계획서를 낸다 — 기말 원고 「우리 일상의 미래」의 출발이다. "자료 없는 방법론이란 불모의 환상"(서호철). (강독 짝은 없다. 2회차 끝에 짝짓기 규칙을 소개한다.)

## 2. 개념
- **자료 검색의 기본 원칙 5개조** — ① 하나의 DB에 의존하지 말 것 ② 키워드 검색의 한계를 알 것(과거 문서는 다른 말을 썼다: '부랑아'·'윤락'·'정화') ③ **자료의 부재도 자료이다** ④ 온라인 검색은 출발점일 뿐(방문 열람·정보공개청구·사서) ⑤ 분류체계와 생산 맥락을 함께 읽을 것(「디지털 자료 찾기」 ver.2025).
- **자료는 국가의 어느 손에서 나왔나** — 법령·관보(국가가 사회를 관리하려 한 틀), 통계(무엇을 세고 안 셌나), 공간정보(항공사진·지적), 공문서(행정 과정), 신문(담론), 사진·유물(일상). 같은 사건도 어느 부에서 찾느냐에 따라 다른 얼굴.
- **부재의 네 이유** — 없는 것은 ① 원래 없음 ② 안 만들어짐 ③ 만들었지만 공개 안 됨 ④ 내 검색어가 틀림 중 무엇인가. 이론적 근거는 조홍진(2025)의 침묵의 층위.
- **자료 메모 5요소** — 서지 / 핵심 주장(자료라면 무엇을 말하는가) / 발췌 / 내 관심과의 관계 / 의문. "자료 30개 모은 사람 ≠ 30개로 글 쓸 수 있는 사람."
- **논문 해부 4질문** — 무엇을 관찰했나 / 시선은 어디에 / 무엇에 엄격한가 / 어떤 글쓰기 구조인가. 5주부터 리뷰 노트 '핵심 주장'의 뼈대.
- **인용 규범** — 출처·수정일·접속일 명기. 온라인 자료는 바뀌고 사이트는 없어진다 — 그래서 접속일. 발언은 ID로.
- **짝짓기 규칙** — 5주부터 두 논문은 기원↔지속 / 층↔층 / 중심↔주변 / 방법↔실전 중 하나로 묶이고, 둘 사이의 긴장이 토론 질문이다.

## 3. 세부 내용 — 수업의 순서
**수업 전에** — 본체 문서 **「역사·사회 연구를 위한 디지털 자료 찾기」**(ver.2025, 전남대 역사문화연구소; 7부 + 원칙 5개조 + 워크숍 프로젝트 5종)를 GitHub `common/guides/`에서 읽어 온다. 수업은 시연·실습 위주다. 학술 DB 보강 1매(RISS·KCI·KRM·PRISM)도 같은 폴더. 노트북 지참. 실습 ① 3주분을 아직 안 냈으면 1회차 전까지 과제 제출 폼으로.

**1회차 (100분) — 발굴·수집: 자료는 어디에 있고, 무엇을 가져오는가**
1. 들어가며 — 3주에서 넘어온 빈칸 (10분) — 3주 그림들에 적힌 "통계가 못 담는 것" 문장 몇 개를 띄운다. 이건 어디 가면 있는가. 오늘의 답: 여러 DB에 흩어져 있고, 어떤 것은 없다.
2. 자료 검색의 기본 원칙 5개조 (15분) — 본체 문서 말미의 원칙을 첫머리로 당겨 읽는다. 이 5개조가 "자료로 사회를 말하는 연습"의 규칙이고, 기말 원고 평가 기준(DB 다양성·교차 검증·검색 실패의 기록)의 원본이다.
   > 📖 김백영 외 2016, 7장 서호철 (p.170) "경험적 연구란 결국 자료의 문제로 귀결된다. 방법이란 자료에서 이야기를 끌어내기 위한 수단과 절차일 뿐, 자료 없는 방법(론)이란 불모의 환상이다. (…) 남들보다 더 폭넓게, 더 깊이 자료를 섭렵하지 않고서는, 새롭고 독창적인 물음 따위는 영영 떠오르지 않을 것이다. 좋은 방법이란 주어진 자료에 잘 어울리는, 그 자료를 잘 다룰 수 있는 방법이다." — 이 주의 첫 문장.
   > 📖 김백영 외 2016, 7장 (p.179~180) "해당 주제의 초심자가 예전처럼 선배 연구자들의 도움을 받아 선행연구의 흐름을 파악하면서 가장 중요한 자료부터 체계적으로 읽지 않고, 혼자 논문 웹 DB나 자료 아카이브의 키워드 검색부터 시작하는 것이 과연 좋은 일일까? (…) 웹 DB 검색 역시 알아서 자료를 척척 찾아주는 편리한 자동 장치가 아니라 자료를 찾아 '발로 뛰는' 작업의 한 부분이며, 직접 시행착오를 겪으면서 몸에 익혀야 할 노하우일 뿐이다." — 오늘 시연하는 7부 DB는 출발점이지 자동 장치가 아니다.
   > 📖 김백영 외 2016, 7장 (p.188) "국가나 지방의 관료제 행정이 작동하는 한 그 부산물로 (…) 호구(戶口)와 토지에 대해서는 오늘날의 행정통계와 비슷한 자료가 산출되지 않았을까 싶지만, 그것도 사정이 복잡하다. (…) 혈연의 친소(親疎)와 적서(嫡庶), 신분의 엄격한 구별과 그에 따른 불평등이 사회를 구성하는 근본원리였던 시대의 '호구', '구수(口數)', '민수(民數)' 등이 오늘날의 '인구(population)'와 같은 개념일까?" — 원칙 5조(분류체계와 생산 맥락). 3주 통계와 7주 조은(호적)을 잇는 다리.
3. 자료는 어디에 있는가 — 7부 압축 시연 (45분) — DB 나열이 아니라 "이 자료는 국가의 어느 손에서 나왔나"로 묶어, 부마다 실제 화면 하나씩 연다.
   - 1부 법령·관보 — law.go.kr(연혁), 국가기록원 관보: "시행규칙까지 읽어야 집행이 보인다."
   - 2부 통계 — KOSIS, 표준분류(KSIC 1963~): "분류체계가 바뀌면 시계열이 끊긴다"(3주 복습). 『조선총독부통계연보』를 열 때의 주의 세 가지: 항목분류=통치의 범주 / 원자료는 없다 / 연보 수치는 집계의 집계.
   - 3부 공간 — 서울/부산 항공사진(1972~), 지적아카이브(1910~18). 교수 시연 사례 소준철(2023) 「청계천에서 난지도로」: 항공사진이라는 공간정보가 무허가주택 단속 체계를 만들고 도시하층민을 청계천에서 난지도로 밀어낸 과정 — 자료가 사람을 움직인다.
   - 4부 공문서 — 국가기록원(기관명 검색), 서울기록원 vs 서울도서관: "키워드보다 기관별 분류→시기별 정렬."
   - 5부 언론 — 뉴스라이브러리(1920~99), 빅카인즈(1990~), 지역지: "지역 연구는 지역지를 — 광주는 무등일보·광주일보 확인."
   - 6부 생활사 — emuseum, 근대기록문화아카이브, 민주화운동 오픈아카이브: 12주·기말 광장 자료의 자리.
   - 7부 기초 DB + 학술 DB — 한국사DB·규장각 + RISS·KCI·KRM·PRISM: "논문도 자료다 — 강독 논문의 참고문헌부터 따라가기."
   - 시연 내내 반복하는 질문 하나: **이 자료를 만든 건 누구이고, 왜 만들었나?**
   > 📖 박명규·서호철 2003 (p.66 / p.118~119) "식민지시기 조선에서 실시된 근대적 인구조사는 크게 두 줄기로 나뉜다. 그 하나는 호구조사다. (…) 궁극적으로 호적에 근거한 상주인구 집계 (…) 두 번째 계열은 국세조사, 곧 센서스이다. / 호구조사인구가 늘 더 적게 측정된 것은 아마 당연한 결과일 것이다. / 오늘날의 학자들이 국세조사의 인구측정치를 훨씬 더 정확한 것으로 평가하는 데 반해, 당시의 여러 문헌들과 특히 조선총독부의 행정에서는 오히려 국세조사인구를 무시하고 매년 집계되었던 '현주호구' 쪽을 선호하는 경향이 뚜렷하였다." — 같은 해 조선 인구가 자료마다 다른 이유. 실습에서 '인구'를 쓸 때 어느 계열인지 밝힌다.
   > 📖 박명규·서호철 2003 (p.123~124) "우리는 일본의 식민권력이 이 땅에서 수집·생산한 조사의 결과물들을 대할 때마다, 우선 이렇게 물어야 한다. 일본제국주의는 왜 그런 조사들을 그토록 열심히 수행했을까? 조사는 얼마나 잘 수행되었고, 이 땅의 일반민중은 그런 조사에 어떤 태도를 취했을까? 조사의 결과들은 얼마나 믿을 만한 것일까?" — 2부 시연 마무리의 체크리스트 세 질문. 식민지 통계만이 아니라 KOSIS·기록원 자료 전부에 던진다.
4. 시드 자료 배포 (20분) — **12·3 이후 시민발언 교수 정제본**(발췌, 발언자 익명화·식별정보 제거) + 비상행동 자료 정제본. 형식은 스프레드시트(발언 ID / 일시 / 장소 / 발언 요지 / 주제 태그). 안내 셋: ① 이것은 현재의 자료다 — 3주 통계에도 4주 DB 어디에도 아직 없는, 지금 만들어지고 있는 사료. 15주에 교수가 이 자료로 무엇을 하는지 보여준다. ② **발언자 보호: 정제본만 사용, 재식별 시도 금지, 인용은 발언 ID로.** ③ 여기서 일상의 주제 하나를 고른다 — 안전·일터·광장·학교·돌봄·주거·먹거리…. 10분 훑어보기: 각자 발언 20건을 읽고 반복되는 일상의 말 3개를 적는다.
5. 마무리·과제 (10분) — 2회차까지 할 것: 시드에서 고른 주제 하나에 대해 오늘 배운 7부 중 **2개 이상의 DB**에서 검색해 온다 — 찾은 것 5건(출처·접속일 기록) + **못 찾은 것 1건**(어디서 무엇을 검색했는데 없었는지) + 학술 DB에서 그 주제의 논문 1편(RISS 검색 → 강독 논문 목록에 있는지 대조).

**2회차 (100분) — 선정·분류·분석: 가져온 것을 어떻게 쌓고 읽는가**
1. 선정 — 무엇을 남길 것인가 (20분) — 공식/비공식 사료 대조: 유신헌법 조문 vs 박완서 「닮은 방들」(아파트 시대). 같은 시대를 국가의 문서와 소설이 어떻게 다르게 담는가. 가져온 5건에 공식/비공식이 섞여 있는지 확인한다. 아카이브 독해 — 부재의 독해(누가 기록에서 빠졌나), 재현된 타자(기록이 대상을 어떻게 그렸나), 출처 윤리. '못 찾은 것 1건'을 여기서 읽는다: 없는 이유가 네 가지 중 무엇인가. 인용 규범: 출처·수정일·접속일. GitHub 저장소의 커밋 이력이 이 규범의 실물이다.
   > 📖 김백영 외 2016, 7장 (p.173) "오늘날 남아 있는 조선시대 문헌 중 상당수는 내용의 중요성보다 글씨가 좋다든지 조상의 유묵(遺墨)이라든지 하는 이유에서 보존된 것이라니까, 가치평가에도 좋게 보면 우연, 길게 보면 구조라고 할 복잡한 사정이 얽혀 있다고 하겠다." — '남은 것'은 왜 남았나. 부재의 반대편도 자료다.
2. 분류 — 모은 것을 어떻게 쌓는가 (25분) — 자료 메모 5요소. 연표 템플릿: 자료를 시간순으로 놓는다 — 시드 발언(2024~25) 옆에 찾아온 과거 자료를 시간축으로 늘어놓으면 기말 원고의 골격(현재→과거→미래)이 그대로 보인다. **반 공동 자료 목록**(GitHub `common/자료목록.csv`, 제출물을 교수가 취합·갱신; 열: 자료명 / 유형 / 생산 주체 / 시기 / 출처 URL / 접속일 / 수집자 / 주제 태그) — 각자 5건을 여기 등록하고, 학기 내내 쌓여 14주 아카이브 발표의 본체가 된다. 논문 해부 4질문을 찾아온 논문 1편에 적용한다 — 5주 리뷰 노트의 예행연습.
3. 분석 — 자료에서 주장으로 (15분) — 문서·신문 분석의 기본(누가·언제·누구에게·왜), 질적 코딩의 첫 단계(반복되는 말에 이름 붙이기 — 1회차에 적은 '반복되는 말 3개'가 이미 코딩), "말해주지 않는 것" 명시. 시연: 시드 발언 10건 + 학생이 찾은 과거 자료 1건을 나란히 놓고 교수가 해석 한 단락을 즉석에서 쓴다 — 주장 → 인용(근거) → 해석 → 한계. 이것이 기말 원고의 한 문단이다.
   > 📖 김백영 외 2016, 7장 (p.197 / p.204) "물론 과거의 일기는 꼭 오늘날과 같은 사생활, 세계와 불화하는 자아의 내면의 기록 같은 것은 아니다. 상당수는 오히려 일종의 (개인적 업무에 대한) 일지(日誌) 같은 것이다. / 구술증언을 하고 또 듣는다는 구술자와 면접자의 대면적 상호작용을 '자료'를 수집하고 '방법'을 가지고 접근해서 그것을 분석·해석한다는 것과는 전혀 다른 경험이어서, 종전의 방법 논의를 그대로 적용하기는 힘들다." — 깊이 읽는 자료(일기·구술). 시드 자료(발언 채록)가 어느 쪽인지 함께 따져 본다.
4. 짝짓기 규칙 소개 — 강독 예고 (10분) — 다음 주부터 매주 논문 2편. 두 논문은 나름의 규칙(기원↔지속, 층↔층, 중심↔주변, 방법↔실전)으로 묶이고, 둘 사이의 긴장이 그 주의 토론 질문. 리뷰 노트 5요소 + "짝의 긴장" + "격자의 자리". 5주 첫 짝: 박명규(2001) ↔ 조계원(2016) — '사회'라는 말은 어디서 왔는가.
5. 실습·제출 (30분) — **아카이빙 계획서** 작성(GitHub `common/templates/archiving_plan.md`): ① 수집 대상(시드에서 고른 주제) ② 목적(큰 물음 / 세부) ③ 대상의 특징(공간적·시간적) ④ 수집 계획(일정 / 어떤 DB에서 어떤 검색어로 / **예상되는 자료의 부재**) ⑤ 기말 원고 「우리 일상의 미래」로 어떻게 이어지는가 한 단락. 제출: 계획서 + 자료 5건 목록(공동 자료 목록 양식 CSV) + 못 찾은 것 1건 + 해석 한 단락 → **과제 제출 폼**(https://forms.gle/9qDjkpWd9wg7fgbX6), 실습 ① 4주분(2~4주 실습 총괄). 평가 기준: 완성도가 아니라 **DB 다양성 · 교차 검증 · 검색 실패의 기록.**
